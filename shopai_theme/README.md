# SHOP AI — Python Full Conversion

This package ports the provided SHOP AI React/TypeScript project to a Python + Flask backend with a server-rendered/vanilla JS frontend.

## Run on Windows

```powershell
python -m pip install -r requirements.txt
python run.py
```

Open `http://127.0.0.1:3000`.
